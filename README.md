
# ⚡ Energy and Power Supply Analysis

## 📌 Project Overview
This project analyzes energy consumption and power supply data using data cleaning, exploratory data analysis (EDA), machine learning, and dashboards.

## 🎯 Objectives
- Clean and preprocess energy data
- Analyze energy consumption patterns
- Perform exploratory data analysis
- Develop a machine learning pipeline
- Visualize insights using dashboards

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook
- Excel

## 📂 Project Structure
```text
energy-and-power-supply-analysis/
├── dashboards/
├── data/
│   └── processed/
├── cleandata.ipynb
├── eda(git).ipynb
├── ml_pipeline.ipynb
└── Energy and Peak DATA.xlsx
```

## 🚀 Installation and Setup

### 1. Clone the repository
```bash
git clone https://github.com/vishal777999/energy-and-power-supply-analysis.git
```

### 2. Navigate to the project directory
```bash
cd energy-and-power-supply-analysis
```

### 3. Install dependencies
```bash
pip install pandas numpy matplotlib seaborn scikit-learn openpyxl jupyter
```

### 4. Run Jupyter Notebook
```bash
jupyter notebook
```
